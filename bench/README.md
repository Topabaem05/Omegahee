# Bench results

Only results produced under `tools/clean_env_check.py` may be added here.
Each JSON or Markdown record must include:

- uzu commit and binary version/hash;
- model repository and checkpoint size;
- GPU utilization and swap at the start and end;
- sample count, median, and standard deviation;
- prompt/context settings;
- exact command.

The pre-reset results are in the `archive/omega-pre-reset-20261018` tag.
